시작하기

모델을 드래그하거나 모델 열기로 불러옵니다. glTF(.gltf)와 OBJ(.obj)는 이미지, .bin, .mtl 등 관련 파일을 함께 선택하거나 폴더 전체 선택을 이용하세요.

UV / 텍스처 검사

Checker/UV Grid/UV Stretch/Vertex RGB/Vertex Alpha를 전환하여 데이터를 검사합니다. V.Alpha는 Material / Checker / UV Grid 위에 겹쳐 켤 수 있습니다. 머티리얼의 Opaque/Blend/Additive/Clip을 조합해 확인하고, UV & Flow에서 X/Y 속도를 조절하세요. +X는 화면의 텍스처가 U+ 방향으로, +Y는 V+ 방향으로 이동하도록 보정합니다.

Vertex Alpha 검증 / 3ds Max

핑크 메시 = 실제로 로드된 Geometry에 Alpha가 없는 상태입니다. 흰색 메시 = RGBA A값이 1.0인 상태입니다. 3ds Max에서 Vertex Alpha(-2)에 페인트하고 Export FBX의 Vertex Colors 옵션을 켠 뒤 재수입하여 확인하세요. Exporter가 A를 전달하지 않은 경우 뷰어가 임의로 복원할 수는 없습니다.

Blender / 3ds Max

.blend와 .max는 브라우저에서 직접 해석할 수 없습니다. Blender는 File → Export → glTF 2.0 (.glb), 3ds Max는 Export → FBX로 변환한 후 불러오세요. 동봉된 Blender 일괄 변환 스크립트도 사용할 수 있습니다.

추가 머티리얼 옵션

Packed ORM 이미지를 올리면 AO(R), Roughness(G), Metallic(B)에 자동 연결합니다. Normal Map Green 반전은 노멀 스케일 Y만 반전하며 원본 이미지를 수정하지 않습니다. 선택 메시의 Material ID별 편집을 지원합니다.

단축 사용법

좌클릭 회전 · 우클릭 패닝 · 휠 줌 · 메시 클릭하여 선택 · Fit으로 화면 맞춤. 원본 모델은 서버로 업로드되지 않습니다. 외부 라이브러리 로딩을 위해 인터넷 연결은 필요합니다.
